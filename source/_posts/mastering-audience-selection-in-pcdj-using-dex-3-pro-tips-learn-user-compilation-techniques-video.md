## Mastering Audience Selection in PCDJ Using DEX 3 Pro Tips - Learn User Compilation Techniques (Video)

One of the latest karaoke features included in DEX 3.11.0.1 (and up) is the ability to access singer/song history so you can add the singer and the songs they wish to sing back to rotation quickly.

![DEX 3 performing karaoke with signer](https://i0.wp.com/pcdj.com/wp-content/uploads/2018/09/42231123_10217815751603269_7143137449177251840_o.jpg?fit=300%2C225&ssl=1 "DEX 3 performing karaoke with signer")

A few customers using [DEX 3](https://tools.techidaily.com/pcdj/products/) to host karaoke events professionally have inquired on how they can move all of a singers songs to a permanent user list (playlist) so they can more easily access their song list — without having to search history (using the “S:” search method).

The inquiring customers also asked that the user list store the singers name _and_ any key changes that were applied in a previous session. While these aren’t technically documented features, they’re not only possible, they’re easy to use.

In the [DEX 3](https://tools.techidaily.com/pcdj/products/) quick tip tutorial video above I demonstrate how you can access singer history, select all songs from the singers history, and swiftly move them all to a permanent user list that can be directly accessed during a future karaoke night.
